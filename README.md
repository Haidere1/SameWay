# 🚗 SameWay – Carpooling App

> A modern, Gen-Z styled carpooling mobile application built with Expo (React Native) and Node.js.

⚠️ **Status: Under Active Development**

---

## 📌 Overview

SameWay is a university-focused carpooling platform that allows users to:
- Offer rides
- Find available rides nearby
- Join rides and share travel costs

---

## 🧠 Tech Stack

### 📱 Frontend (Mobile)
- Expo (React Native)
- Expo Router
- React Navigation

### ⚙️ Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication

---

## ✨ Features

- 🔐 User Authentication (Signup / Login)
- 🚗 Create Ride
- 📍 View Available Rides
- 🤝 Join Ride
- 🗺️ Map Integration
- 🎮 Dark Neon “Game-style” UI
